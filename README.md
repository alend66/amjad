An anime cyberpunk-themed interactive cybersecurity portfolio engineered for **Amjad T.S**, Certified Ethical Hacker (CEH) & SIEM Log Monitoring specialist.

![Anime Hero Avatar](assets/amjad_anime.jpg)

## 🌟 Key Features

- **Dual Persona Switcher**: Seamlessly toggles between Anime Protagonist Mode and Real Operative Mode with an anime speedline hologram effect.
- **Dynamic Falling Sakura & Matrix Dust Canvas**: Interactive HTML5 Canvas particle system responsive to air movement and mouse drag.
- **Web Audio API Sound Effects**: Synthesized katana blade slash ("*SHING!*") and cyber HUD beeps without any external audio asset overhead.
- **Interactive Cyber Terminal (CLI)**: Interactive prompt supporting commands like `help`, `whoami`, `skills`, `projects`, `scan`, `ceh`, `resume`, `contact`.
- **Dedicated Resume & Cyber Dossier**: Includes both a styled anime cyberpunk dossier and a live embedded PDF document reader with 1-click download.
- **Mission Showcases**: Interactive Splunk SIEM and Wazuh EDR incident simulation modals.
- **EC-Council Certified Ethical Hacker (CEH)**: Verified credential highlights.

## 🛠️ Tech Stack

- **Core**: Semantic HTML5, CSS3 (Vanilla Glassmorphism & Cyberpunk Design System), Vanilla JavaScript (ES6+)
- **Graphics & Audio**: HTML5 Canvas (Sakura physics & matrix dust), Web Audio API (Synthesized SFX)
- **Typography**: Google Fonts (*Orbitron*, *Rajdhani*, *Poppins*, *Noto Sans JP*, *JetBrains Mono*)
- **Icons**: FontAwesome 6

## 🚀 Getting Started

Clone the repository and run locally:

```bash
git clone https://github.com/<your-username>/amjad-anime-portfolio.git
cd amjad-anime-portfolio
```

Run with Node.js built-in server:
```bash
node server.js
```
Then visit `http://localhost:3000` in your browser.

Or simply open `index.html` in any modern web browser!
